# Fonts / Fuentes

## English

The official brand manual identifies:
- Aeonik as the primary corporate typeface.
- Taviraj as the secondary corporate typeface.
- Arial as the system fallback when Aeonik is not available, including email and PowerPoint environments.

Font binaries are not included in this skill. Add them only if CUNEF's font licences expressly permit redistribution through the organization's Claude environment.

## Español

El manual oficial identifica:
- Aeonik como tipografía corporativa principal.
- Taviraj como tipografía corporativa secundaria.
- Arial como tipografía de sistema cuando Aeonik no esté disponible, incluidos correo electrónico y PowerPoint.

Los archivos binarios de las fuentes no están incluidos. Solo deben añadirse si las licencias de CUNEF permiten expresamente su redistribución mediante el entorno de Claude de la organización.
