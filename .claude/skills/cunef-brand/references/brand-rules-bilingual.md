# CUNEF brand rules / Reglas de marca CUNEF

## 1. Logo / Logotipo

**English**
- Use the orange positive logo as the default on white or light backgrounds.
- Use the white negative version on the corporate orange or on suitably dark backgrounds when available.
- Use monochrome versions only exceptionally when color cannot be used or legibility requires it.
- Maintain clear space around the logo equivalent to the width of the letter “U”.
- Minimum size: 10 mm in print and 40 px in digital media.
- On photography, select the version with the highest contrast and prefer clean, low-noise image areas.

**Español**
- Usar como opción predeterminada el logotipo positivo naranja sobre fondos blancos o claros.
- Usar la versión negativa blanca sobre el naranja corporativo o fondos suficientemente oscuros cuando esté disponible.
- Utilizar versiones monocromas solo de forma excepcional, cuando no pueda emplearse color o sea necesario para asegurar la legibilidad.
- Mantener un área de seguridad equivalente al ancho de la letra «U» alrededor del logotipo.
- Tamaño mínimo: 10 mm en impresión y 40 px en soportes digitales.
- Sobre fotografía, elegir la versión con mayor contraste y zonas limpias con poco ruido visual.

### Never / Nunca

Do not distort, alter proportions, crop, mask, rotate, add opacity, outlines or gradients, change colors, or recompose the logo.

No deformar, alterar proporciones, recortar, enmascarar, rotar, aplicar opacidad, filetes o degradados, cambiar colores ni modificar la composición del logotipo.

## 5. Typography / Tipografía

**English**
- Primary corporate typeface: Aeonik, for titles, subtitles, and body text.
- Use Aeonik Medium for emphasis.
- Secondary typeface: Taviraj, for supporting text, selected titles, or decorative elements.
- System fallback: Arial, especially for tools where Aeonik is unavailable, including email and PowerPoint.

**Español**
- Tipografía corporativa principal: Aeonik, para títulos, subtítulos y cuerpos de texto.
- Usar Aeonik Medium para destacar palabras.
- Tipografía secundaria: Taviraj, para textos de apoyo, determinados títulos o elementos decorativos.
- Tipografía de sistema: Arial, especialmente en herramientas donde Aeonik no esté disponible, como correo electrónico o PowerPoint.

## 6. Templates / Plantillas

- Word: use `assets/templates/cunef-document-template.docx` as the base and preserve its styles, headers, footers, tables, numbering, and document hierarchy.
- PowerPoint: use `assets/templates/cunef-presentation-template.pptx` as the base and preserve its master slides, layouts, page numbering, and predefined hierarchy.

- Word: usar `assets/templates/cunef-document-template.docx` como base y conservar estilos, encabezados, pies, tablas, numeración y jerarquía.
- PowerPoint: usar `assets/templates/cunef-presentation-template.pptx` como base y conservar patrones, diseños, numeración y jerarquía predefinida.

## 7. Final compliance checklist / Lista final de comprobación

- Correct official template used / Plantilla oficial correcta utilizada.
- Correct logo version and sufficient contrast / Versión correcta del logo y contraste suficiente.
- Logo proportions and clear space preserved / Proporciones y área de seguridad respetadas.
- Official colors only / Solo colores oficiales.
- Corporate or approved fallback typography / Tipografía corporativa o alternativa aprobada.
- No overcrowded pages or slides / Sin páginas o diapositivas sobrecargadas.
- Consistent spacing, hierarchy, and alignment / Espaciado, jerarquía y alineación coherentes.
- Language, spelling, and institutional naming reviewed / Idioma, ortografía y denominaciones institucionales revisados.
- Accessibility checked: contrast, readable sizes, alt text where applicable / Accesibilidad revisada: contraste, tamaños legibles y texto alternativo cuando corresponda.
