# CUNEF Universidad brand / Marca CUNEF Universidad

Apply the official CUNEF Universidad identity consistently. Follow the bilingual rules below and use the bundled files whenever relevant.

Aplicar de forma coherente la identidad oficial de CUNEF Universidad. Seguir las reglas bilingües siguientes y utilizar los archivos incluidos cuando corresponda.

## Source of truth / Fuente de referencia

- Treat `references/cunef-brand-guidelines-es.pdf` as the authoritative brand manual.
- Consult `references/brand-rules-bilingual.md` for the operational summary.
- If any instruction conflicts with the official PDF, the PDF prevails.

- Considerar `references/cunef-brand-guidelines-es.pdf` como manual de marca oficial y fuente principal.
- Consultar `references/brand-rules-bilingual.md` para el resumen operativo.
- Si existe alguna contradicción, prevalece el PDF oficial.

## Bundled assets / Recursos incluidos

- Logo: `assets/logos/cunef-universidad-orange-transparent.png`
- Word template: `assets/templates/cunef-document-template.docx`
- PowerPoint template: `assets/templates/cunef-presentation-template.pptx`
- Font information: `assets/fonts/README.md`

## Mandatory workflow / Flujo obligatorio

1. Identify the requested output type, audience, language, and purpose.
2. Use the matching official template as the base whenever the output is Word or PowerPoint.
3. Preserve the template's masters, page size, margins, headers, footers, numbering, and institutional elements unless the user explicitly requests an exception.
4. Apply the official logo, color, typography, contrast, and clear-space rules.
5. Keep the visual style clean, professional, accessible, and appropriate for a university.
6. Before delivery, run the brand-compliance checklist in `references/brand-rules-bilingual.md`.

1. Identificar el tipo de salida, el público, el idioma y el objetivo.
2. Usar la plantilla oficial correspondiente como base para Word o PowerPoint.
3. Conservar patrones, tamaño, márgenes, encabezados, pies, numeración y elementos institucionales, salvo petición expresa.
4. Aplicar las reglas oficiales de logotipo, color, tipografía, contraste y área de seguridad.
5. Mantener un estilo limpio, profesional, accesible y adecuado para una universidad.
6. Antes de entregar, aplicar la lista de comprobación de `references/brand-rules-bilingual.md`.

## Language behavior / Comportamiento lingüístico

- Respond and create content in the language requested by the user.
- Recognize both English and Spanish instructions.
- Do not translate official names, legal names, URLs, or fixed brand expressions unless the user requests it.
- For bilingual deliverables, keep terminology consistent across both versions.

- Responder y crear el contenido en el idioma solicitado.
- Reconocer instrucciones tanto en inglés como en español.
- No traducir nombres oficiales, denominaciones legales, URL o expresiones fijas de marca salvo petición expresa.
- En materiales bilingües, mantener terminología equivalente y consistente.

## Document creation rules / Reglas para documentos

### Word

- Start from `assets/templates/cunef-document-template.docx`.
- Reuse its built-in heading, body, table, header, footer, and numbering styles.
- Preserve the document hierarchy and automatic table of contents when present.
- Avoid recreating the template from scratch when the original can be used.

- Partir de `assets/templates/cunef-document-template.docx`.
- Reutilizar sus estilos de títulos, cuerpo, tablas, encabezados, pies y numeración.
- Conservar la jerarquía y el índice automático cuando exista.
- Evitar reconstruir la plantilla desde cero si puede usarse el original.

### PowerPoint

- Start from `assets/templates/cunef-presentation-template.pptx`.
- Prefer existing layouts and slide masters.
- Use the template's established hierarchy: chapter title, slide title, level-two heading, and body text.
- Keep slides concise and visually balanced. Do not overcrowd them.
- Use charts, tables, and images only when they improve comprehension.

- Partir de `assets/templates/cunef-presentation-template.pptx`.
- Priorizar los diseños y patrones existentes.
- Respetar la jerarquía de título de capítulo, título de diapositiva, titular de nivel dos y cuerpo.
- Mantener diapositivas sintéticas y equilibradas, sin sobrecargarlas.
- Utilizar gráficos, tablas e imágenes solo cuando mejoren la comprensión.

### PDF and other outputs / PDF y otras salidas

- When generating a PDF, first create it from the appropriate official Word or PowerPoint template when practical.
- Preserve selectable text, reading order, sufficient contrast, and accessible structure.
- For images, banners, or social graphics, follow the logo and color rules even when no document template applies.

- Para generar un PDF, crearlo preferentemente desde la plantilla oficial de Word o PowerPoint correspondiente.
- Mantener texto seleccionable, orden de lectura, contraste suficiente y estructura accesible.
- En imágenes, banners o piezas sociales, aplicar las reglas de logotipo y color aunque no exista plantilla documental.

## Prohibited actions / Acciones prohibidas

- Do not distort, rotate, crop, mask, outline, add gradients to, recolor, or change the composition of the logo.
- Do not invent unofficial colors, fonts, sub-brands, signatures, or layout systems.
- Do not use low-contrast logo placements or visually noisy backgrounds.
- Do not replace the official templates with a generic design merely for aesthetic preference.

- No deformar, rotar, recortar, enmascarar, perfilar, aplicar degradados, recolorear ni alterar la composición del logotipo.
- No inventar colores, fuentes, submarcas, firmas o sistemas de maquetación no oficiales.
- No colocar el logo con poco contraste ni sobre fondos visualmente ruidosos.
- No sustituir las plantillas oficiales por un diseño genérico solo por preferencia estética.

## Missing assets / Recursos no incluidos

The commercial Aeonik font files and Taviraj font files are not bundled. Use Arial as the system fallback where the corporate fonts are unavailable, in line with the official manual. Never claim that a font file is included when it is not.

Los archivos de las fuentes comerciales Aeonik y Taviraj no están incluidos. Utilizar Arial como tipografía de sistema cuando las fuentes corporativas no estén disponibles, conforme al manual oficial. No afirmar nunca que una fuente está incluida si no lo está.
